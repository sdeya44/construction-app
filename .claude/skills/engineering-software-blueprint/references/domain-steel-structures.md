## 1. מה המשתמש באמת צריך

אין טעם לבנות Tekla או Advance Steel. מאות שנות-אדם הושקעו בהם.
הערך של תוכנה ייעודית הוא ב**טיפולוגיה צרה וחוזרת**: סככות, פרגולות, מחסנים, גגוני חניה, עם פרמטרים ופרטי חיבור סטנדרטיים של החברה.
- הקלט: כמה מספרים.
- הפלט: חבילת ייצור מלאה תוך דקות, במקום ימים של שרטט.

אם המשתמש מבקש "כל מבנה פלדה", מאתגרים את זה ומציעים להתחיל מסוג מבנה אחד.

## 2. מילון מונחים

| מונח | הגדרה |
|---|---|
| Grid / צירים | רשת צירים ומפלסים, שאליה מתייחסים כל האלמנטים |
| Member / אלמנט | עמוד, קורה, מרישה (purlin), חיזוק (bracing), שבכה (truss) |
| Profile / חתך | IPE, HEA/HEB, UPN, RHS/SHS, CHS, L, פח מכופף (C/Z), מקטלוג עם תכונות |
| Material / חומר | S235 / S275 / S355; גלוון חם או צבע |
| Part / חלק | פריט ייצור בודד: פרופיל חתוך או פלטה |
| Assembly / מכלול | חלק ראשי עם חלקים מרותכים אליו, שיוצאים מהמפעל כיחידה אחת. מקבל **סימון (mark)** |
| Connection / חיבור | פלטת בסיס, ראש עמוד, חיבור קורה-עמוד (end plate / fin plate), חיבור מרישה (cleat), ברך (haunch) |
| Bolt / Weld | ברגים (קוטר, דרגה 8.8/10.9, אורך, אומים ודסקיות), ריתוך (סוג, a-מידה, אורך, צד) |
| Anchor / עוגן | ברגי עיגון לבטון ותוכנית עוגנים |
| Shop drawing | שרטוט מכלול או חלק לייצור, עם מידות, חורים, ריתוכים ורשימת חלקים |
| GA / Erection drawing | תוכנית כללית והרכבה באתר, עם סימוני מכלולים |
| NC / DSTV (.nc1) | קובץ למכונות חיתוך וקידוח פרופילים |
| Nesting | שיבוץ חלקים בפרופיל באורך מסחרי (6/12 מ') או בלוח פח |
| Revision | מהדורת שרטוט, עם מעקב שינויים |

## 3. זרימת עבודה

```
פרמטרים (מפתח, אורך, גובה, שיפוע, מרווח שדות, עומסים*)
  → גנרטור גאומטריה: צירים + אלמנטים + חתכים
  → בדיקת חתכים* (אופציונלי, ע"פ ת"י 1225 / EN 1993) — סיוע בלבד, אישור מהנדס
  → הצבת חיבורים מתבניות (Connection templates) לפי סוג מפגש
  → פירוק לחלקים, אחר כך מכלולים, אחר כך מספור (חלקים זהים = אותו סימון)
  → תוצרים: שרטוטי מכלול, שרטוטי חלק, תוכנית עוגנים, תוכנית הרכבה,
            רשימת חומרים (BOM) ומשקלים, רשימת ברגים, NC1, DXF, IFC, אומדן מחיר
```
\* חישוב סטטי הוא אחריות מהנדס רשוי. התוכנה מציגה הנחות ומקדמים, ולא חותמת.

## 4. מודל נתונים

כל המידות במ"מ, וכל המשקלים בק"ג.

- `project`: לקוח, אתר, תקן, חומר וגימור ברירת מחדל.
- `structure`: סוג (`pergola` / `canopy` / `shed`), פרמטרים ב-JSON, גרסה (שרשרת `origin/parent`).
- `grid`: צירים ומפלסים.
- `member`: נקודת התחלה וסוף (xyz), חתך, סיבוב, offset, תפקיד (column/rafter/purlin/brace).
- `profile_catalog`: נתוני חתך (h, b, tw, tf, r, A, משקל/מ'). קטלוג חיצוני מיובא, לא בקוד.
- `connection`: סוג תבנית, פרמטרים, האלמנטים המחוברים.
- `part`: גאומטריה סופית, חיתוכים (cuts/copes), חורים, אורך ומשקל, `part_mark`.
- `assembly`: חלק ראשי, חלקים משניים, ריתוכים, `assembly_mark`, כמות.
- `bolt_group`, `weld`.
- `drawing`: סוג, ישות, גיליון, קנה מידה, `revision`, סטטוס (טיוטה / לאישור / לייצור). נעילה אחרי "לייצור".

**כלל:** המודל הוא מקור האמת. שרטוטים ו-BOM נגזרים ממנו תמיד ולא נערכים ידנית. אם צריך עריכה ידנית, היא נשמרת כ"override" שגלוי ומסומן.

## 5. מנוע גאומטריה וחיבורים

- **גאומטריה:** סוליד פרמטרי לכל חלק, בצורת extrude של חתך לאורך ציר.
  - חיתוכים מבוצעים במישור (miter, cope) ובגזירה לפי פלטות.
  - ספריות אפשריות: OpenCascade (opencascade.js / CadQuery בפייתון) ל-B-rep אמיתי, או רשתות בלבד (three.js) לתצוגה. **המלצה:** גאומטריה אנליטית משלנו לפרופילים, שהיא מספיקה לחיתוך וקידוח ישרים, ו-OpenCascade רק אם נדרשים חיתוכים מורכבים.
- **תבניות חיבור:** כל תבנית היא פונקציה `(members, params) → parts + bolts + welds + cuts`. מתחילים ב-4–6 תבניות:
  - פלטת בסיס;
  - קורה-עמוד (end plate);
  - ראש עמוד;
  - מרישה על קורה (cleat);
  - חיבור באמצע קורה (splice);
  - חיזוק X.
- **בדיקות גאומטריה:** אין התנגשויות (clash), מרחקי ברגים מקצה ובין ברגים לפי תקן, גישה למפתח, וחורי ניקוז ואוורור לגלוון.
- **מספור:** חלקים זהים בגאומטריה, בחומר ובחורים מקבלים אותו סימון (hash קנוני של הגאומטריה, לא תלוי במיקום). מספור יציב בין מהדורות: חלק שלא השתנה שומר על הסימון שלו.

## 6. תוצרים ופורמטים

| תוצר | פורמט | הערות |
|---|---|---|
| שרטוט מכלול | PDF + DXF, ‏A3 | מבטים אורתוגרפיים, מידות שרשרת ומצטברות, חורים, סימני ריתוך (ISO 2553), טבלת חלקים, כותרת (title block) |
| שרטוט חלק | PDF + DXF, ‏A4 | פלטה עם קונטור וחורים; פרופיל עם חיתוכים |
| תוכנית עוגנים | PDF/DXF | מידות לצירים, קוטר וגובה בולט |
| תוכנית הרכבה | PDF | מבט על וחזיתות עם סימוני מכלולים |
| BOM / משקלים / ברגים | Excel מעוצב כמו ה-PDF | לפי מכלול, לפי חתך, סיכום טון |
| NC | DSTV .nc1 | בלוקים ST, BO, AK, IK, SI. נבדק בטעינה חוזרת |
| פלטות לחיתוך | DXF לפלזמה/לייזר | קונטור סגור, שכבות לפי עובי |
| מודל | IFC4 (web-ifc / IfcOpenShell) | לתיאום עם אדריכלות |
| אומדן | Excel / כתב כמויות | ק"ג × מחיר + ברגים + גלוון. אפשר להתחבר ל-KAYAN BOQ |

**הלב הקשה: שרטוט אוטומטי.**
- הקרנה אורתוגרפית של הסולידים, עם קווים נסתרים כאשר צריך.
- בחירת מבטים וחתכים לפי סוג מכלול.
- מיקום מידות בלי התנגשויות.

ממליצים על **תבנית שרטוט לכל סוג מכלול** (עמוד עם פלטת בסיס, קורה עם end plates), שבה כללי המידות קבועים, במקום מנוע מידות כללי.

## 7. ארכיטקטורה מומלצת

- **Desktop:** ‏Electron, או web אופליין. מאותו בסיס כמו KAYAN לשימוש חוזר בתשתית הדפסה, אקסל ו-UI.
- **תצוגה תלת-ממדית:** three.js, עם בחירה (picking), חתכים ומבטים.
- **מנוע:** TypeScript או JS טהור לגאומטריה ולחיבורים. אם נדרש B-rep, מוסיפים מנוע פייתון (CadQuery/OCC) כתהליך צדדי.
- **DB:** SQLite (פרויקט = קובץ), קטלוג פרופילים כקובץ נפרד.
- **שרטוט:** מחולל SVG פנימי, שממנו מפיקים PDF (printToPDF) ו-DXF (writer ייעודי).
- **בדיקות:**
  - golden files ל-DXF ול-NC1;
  - בדיקות משקל מול חישוב ידני;
  - snapshot לצילומי שרטוט.

## 8. MVP ואבני דרך

1. **גנרטור סככה פרמטרית:** תצוגה תלת-ממדית ורשימת אלמנטים, משקל ואומדן. *זה כבר מוכר הצעות מחיר.*
2. **תבניות חיבור:** פלטת בסיס וקורה-עמוד. חלקים, ברגים, ריתוכים ובדיקת מרחקים.
3. **מספור ומכלולים, BOM מעוצב באקסל ו-PDF.**
4. **שרטוטי חלק (פלטות) ו-DXF לחיתוך, ותוכנית עוגנים.**
5. **שרטוטי מכלול לפי תבנית, ו-NC1.**
6. **מהדורות ונעילה "לייצור", IFC.**

## 9. סיכונים ומה לאתגר

- **שרטוט אוטומטי:** הסיכון הגבוה ביותר. מתחילים בפלטות, שהן דו-ממדיות, ורק אחר כך עוברים למכלולים.
- **אחריות סטטית:** לא לשווק "חישוב". לסמן "עזר תכנוני, טעון אישור מהנדס".
- **פורמט NC:** כל מכונה מעט שונה. משיגים מהמפעל קובץ דוגמה ומכונה לבדיקה כבר באבן דרך 1.
- **קטלוג פרופילים:** מקור מוסמך ומוגן זכויות לא נכנס לריפו ציבורי.
- **מספור לא יציב** בין מהדורות שובר את רצפת הייצור. לבדוק את זה מוקדם.
- **פרטי החיבור של החברה** הם הידע הייחודי. לאסוף 10 שרטוטים אמיתיים מהעבר לפני שמתכננים תבניות.
