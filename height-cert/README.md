# אישורי הדרכה – עבודה בגובה

אפליקציית PWA להנפקת "אישור על הדרכת עובד לביצוע עבודה בגובה" (תוספת, תקנה 5(2)), רישום מעסיקים ועובדים ומעקב תוקף.

- הנתונים נשמרים בדפדפן במכשיר בלבד. יש ייצוא/ייבוא גיבוי בהגדרות.
- אין בקוד פרטים אישיים. פרטי המדריך מוזנים בהגדרות.
- כתובת: `/height-cert/` תחת אתר ה-Pages של המאגר.
