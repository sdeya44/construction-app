# סנכרון לגוגל שיטס – הוראות התקנה

**הדרך הקלה:** באפליקציה, הגדרות ← סנכרון לגוגל שיטס ← כפתור ① "הכנת הסקריפט והמפתח". הוא יוצר מפתח סודי, מעתיק סקריפט מוכן שכולל אותו, ומציג את ההוראות. ההוראות הידניות למטה נשארות כגיבוי.

מבוצע פעם אחת, בחשבון הגוגל של אחמד.

1. פותחים גיליון חדש: https://sheets.new ונותנים לו שם, למשל "אישורי גובה".
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. מוחקים את הקוד שמופיע, ומדביקים את כל התוכן של `Code.gs`.
4. בשורה `const SECRET = '...'` מחליפים את הטקסט בסיסמה ארוכה וייחודית (20 תווים ומעלה, אותיות באנגלית וספרות). שומרים אותה, כי היא תוזן באפליקציה.
5. לוחצים **Deploy ← New deployment**, וב"Select type" בוחרים **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   
   לוחצים Deploy ומאשרים הרשאות (Advanced ← Go to project ← Allow).
6. מעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).
7. באפליקציה: **הגדרות ← סנכרון לגוגל שיטס**, מדביקים את הכתובת ואת המפתח, ולוחצים "שמירה וסנכרון".

מומלץ להפעיל אימות דו-שלבי בחשבון הגוגל, כי הגיליון יכיל ת.ז. של עובדים.

אחרי כל שינוי בקוד: Deploy ← Manage deployments ← Edit ← New version.
