# מציל חיים — הצעות מחיר (PWA)

אפליקציית טלפון להפקת הצעות מחיר בפורמט זהה למסמך שמופק מהתוכנה במשרד (כותרת + לוגו, טבלת פריטים, סיכום, חתימה).

## שימוש
1. פותחים את הקישור בטלפון → "הוסף למסך הבית" (ב-iPhone: Safari ← שיתוף ← הוסף למסך הבית).
2. **הגדרות**: לבדוק קידומת + מספר הבא, שם מפיק המסמך.
3. **+ הצעה חדשה** → לקוח, פריטים, שמור והפק → **שתף PDF** (וואטסאפ/מייל) או **הורד PDF**.

- כל שורה בתיאור פריט = שורה במסמך; המחיר מודפס בשורה האחרונה של הפריט. כמות ריקה = שורת טקסט בלבד.
- ☆ על פריט שומר אותו ב**מחירון** לשימוש חוזר. לקוחות נשמרים אוטומטית (השלמה בשדה "לכבוד").
- מסמך ארוך מתחלק אוטומטית לדפים ("דף X מתוך N"), הסיכום והחתימה בדף האחרון.
- עובד גם בלי אינטרנט (אחרי פתיחה ראשונה).

## נתונים
הכל נשמר **מקומית בטלפון** (localStorage). אין שרת ואין סנכרון בין מכשירים.
גיבוי/שחזור: הגדרות ← ייצוא גיבוי (קובץ JSON).

## מבנה
```
index.html, manifest.json, sw.js
css/doc.css   — פריסת המסמך A4 (מידות נמדדו מהמסמך המקורי)
css/app.css   — ממשק הטלפון
js/doc.js     — חישובים, עימוד, יצירת PDF (html2canvas + jsPDF)
js/store.js   — שמירה מקומית, מספור, גיבוי
js/app.js     — מסכים
assets/header.jpg — כותרת המסמך (נלקחה מה-PDF המקורי)
```
בעדכון גרסה: להעלות את `VERSION` ב-`sw.js`.
