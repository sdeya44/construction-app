# כלי חישוב כמויות הנדסי

אפליקציית Web מקומית לחישוב כמויות אלמנטים מתוך תוכניות PDF / תמונות / שרטוטים,
והפקת דפי חישוב כמויות בגודל A4 הניתנים לביקורת והגשה.

הכלי רץ מקומית בדפדפן, **ללא שרת, ללא ענן, ללא התחברות**. כל הנתונים נשמרים
במחשב בלבד (IndexedDB) עם שמירה אוטומטית.

---

## הרצה מהירה

דרושה התקנה חד-פעמית של [Node.js](https://nodejs.org) (גרסה 18 ומעלה).

```bash
cd quantity-calculator
npm install      # התקנת ספריות (פעם אחת)
npm run dev      # הפעלת האפליקציה
```

לאחר מכן ייפתח כתובת מקומית (לדוגמה `http://localhost:5173`) — פתחו אותה בדפדפן.

### בנייה לגרסה מוכנה (אופציונלי)

```bash
npm run build    # מייצר תיקיית dist/ עם קבצים סטטיים
npm run preview  # הצגת הגרסה הבנויה
```

ניתן להעתיק את תיקיית `dist/` לכל מחשב ולהגיש אותה דרך כל שרת סטטי פשוט.

## למה הסטאק הזה?

נבחר **React + TypeScript + Vite + PDF.js + IndexedDB** (אפשרות 1 שהוצעה):

- **אין צורך בהתקנה כבדה כמו Electron** — רץ בכל דפדפן מודרני, קל להפצה ולגיבוי.
- **PDF.js** ממיר עמודי PDF לתמונות באיכות גבוהה לצורך מדידה מדויקת.
- **IndexedDB** שומר פרויקטים גדולים (כולל תמונות תוכניות) מקומית, ללא הגבלת הנפח של LocalStorage.
- **TypeScript + מבנה מודולרי** — קל להרחיב ולהוסיף יכולות בהמשך.
- אם תרצו בעתיד אפליקציית Desktop אמיתית, אפשר לעטוף את אותו קוד ב-Electron כמעט ללא שינוי.

## תהליך עבודה מומלץ

1. **פרטי פרויקט** — מלאו שם פרויקט, מזמין, קבלן, מספר ומכין החישוב.
2. **ספריית סעיפים** (פאנל ימני) — צרו סעיפים עם קוד, שם ויחידה (מ׳ / מ״ר / מ״ק / יח׳ ...).
3. **ייבוא תוכנית** — העלו PDF (כל עמוד הופך ללשונית) או תמונה.
4. **קביעת קנה מידה** — סמנו שני נקודות על קו ידוע והזינו את אורכו האמיתי במטרים.
   המערכת תחשב פיקסלים למטר ותשמור קנה מידה **נפרד לכל עמוד**.
5. **מדידה** — בחרו כלי (אורך / שטח / ספירה), מדדו על השרטוט, ושייכו לסעיף.
6. **חישוב ידני** — לחילופין הזינו מידות ידנית (אורך × רוחב × גובה וכו׳).
   כל שורה מציגה **נוסחה מלאה** וכמות.
7. **דוח A4** — הפיקו דוח (כל הסעיפים / סעיף בודד / סיכום) והדפיסו או שמרו כ-PDF.
8. **ייצוא** — Excel / CSV של הטבלה, או גיבוי JSON של כל הפרויקט.

> **בדיקה מהירה:** בהפעלה ראשונה נטען אוטומטית **פרויקט דוגמה** עם 4 סעיפים
> ו-8 שורות חישוב (כולל הפחתות), כדי שתוכלו לבדוק מיד את הטבלה, הסיכומים ודוח ה-A4.
> אפשר גם לייבא את `sample-project.json` דרך "ייבוא JSON".

## ביקורת הנדסית

כל שורה ניתנת לבדיקה מלאה: סעיף, עמוד מקור, מידות, **נוסחה מוצגת**, תוצאה ויחידה.
שורות הפחתה מסומנות באדום ובכמות שלילית. בדוח ה-A4 מופיעים מקומות לחתימת
מכין החישוב ולבדיקת מהנדס.

## מה כבר ממומש (MVP מלא)

- ניהול פרויקט מלא + שמירה אוטומטית + פתיחה/מחיקה + גיבוי וייבוא JSON.
- טעינת PDF רב-עמודי ותמונות; זום, Pan, התאמה למסך, סיבוב, מעבר עמודים.
- קנה מידה לכל עמוד + אזהרה כשאין קנה מידה.
- מדידות: אורך, פוליליין, שטח פוליגון/מלבן, ספירת פריטים.
- **שכבת מדידות קבועה** צבעונית על התוכנית (כחול=אורך/שטח, ירוק=ספירה, אדום=הפחתה), הנשמרת לכל עמוד.
- **תצלום אזור (crop) אוטומטי** לכל מדידה — נחתך מהתוכנית עם הסימון עליו, ומוצג בעורך, בטבלה ובדוח ה-A4 לצד הנוסחה, לביקורת קלה.
- **הדגשה דו-כיוונית**: מעבר עכבר על שורה בטבלה מדגיש את אזור המדידה על התוכנית.
- **כלי ניכוי (cut-out)**: סימון חור בתוך שטח שנמדד — השטח נטו מחושב אוטומטית (ברוטו − ניכויים), והחור מסומן באדום על התוכנית ובדוח.
- חישוב ידני: אורך, שטח (מלבן/משולש/טרפז/עיגול), נפח (תיבה/גליל), ספירה — עם מקדם, כמות יחידות והפחתות.
- טבלת חישובים: הוספה, עריכה, מחיקה, שכפול, קיבוץ וסיכום לפי סעיף, סינון.
- סיכומים: לכל סעיף, תוספות, הפחתות, נטו.
- דוח A4 (מפורט / לפי סעיף / סיכום) להדפסה ו-PDF.
- **כמויות חפירה/מילוי בחתכים** (כפתור 📐): שרטוט פרופיל קיים + מתוכנן על קנבס, חישוב שטחי חפירה/מילוי לכל חתך (מ״ר), ונפחים בין חתכים בשיטת שטח קצה ממוצע (Average End Area) במ״ק, כולל ייצוא דוח PDF עם תמונות החתכים. הנתונים נשמרים בתוך הפרויקט.
- ייצוא Excel / CSV / JSON, ו-Undo.

## רעיונות להמשך פיתוח

- עריכת שורות ישירות בטבלה (inline), גרירה לשינוי סדר.
- עמודת מחיר אופציונלית וסיכום כספי.
- שמירת מדידות כשכבה גרפית קבועה על התוכנית.
- ייצוא PDF ישיר ללא תיבת הדפסה.
