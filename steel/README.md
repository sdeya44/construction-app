# KAYAN STEEL PRO

מידול פרמטרי תלת־ממדי ופירוט פלדה (Steel Detailing) — סככות ו-Portal Frames. PWA בעברית, עובד ללא רשת.

> ⚠ **אינו תכן הנדסי מאושר.** נתוני החתכים אינם מאומתים, ואין בדיקת חוזק. מגע גיאומטרי אינו אישור ביצוע.

## הפעלה
```bash
cd steel
npm install
npm run dev          # פיתוח: http://localhost:5173
npm run build && npm run preview   # גרסת ייצור: http://localhost:4173
```

## בדיקות
```bash
npm test             # בדיקות יחידה (Vitest)
npm run test:e2e     # בדיקות דפדפן (Playwright) + צילומי ראיה ב-e2e-results/evidence
npm run test:all     # typecheck + יחידה + build + דפדפן
```

## מבנה
```
src/core        יחידות, וקטורים
src/model       טיפוסים, ברירות מחדל, ולידציה, מיגרציות סכמה
src/profiles    ספריית חתכים וחומרים (לא מאומת), גיאומטריית חתך ותכונות
src/geometry    גזירת מודל מפרמטרים, צירים מקומיים, אקסטרוזיה עם חיתוכי קצה
src/commands    פקודות טהורות + Undo/Redo
src/persist     IndexedDB, קבצים
src/view        מנוע תצוגה three.js: מבטים, בחירה, מדידה, חתך
src/ui          ממשק React (RTL)
docs/           ADR, מטריצת דרישות, החלטות פתוחות, דוח בדיקות
```
