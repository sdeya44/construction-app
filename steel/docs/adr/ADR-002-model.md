# ADR-002 — מודל נתונים, יחידות, מזהים והתאמות ידניות

**סטטוס:** מאושר · **תאריך:** 14.11.2026

1. **יחידות:** כל אורך במודל ב-mm. המרה מטר↔מ"מ רק ב-`src/core/units.ts`. שיפוע = יחס; זוויות ברדיאנים.
2. **קואורדינטות:** X רוחב, Y אורך, Z גובה (Z+ = מעלה). ציר א ב-x=0, ציר ב ב-x=width. מסגרות ממוספרות 1..n לפי Y.
3. **גבהים:** ברירת מחדל `heightRef = TOS` — גובה עמוד/רכס = פני עליון של קורת הגג בציר העמוד. ניתן לשנות ל-AXIS (ציר הקורה). *הנחה — לאישור, ראה gaps.md.*
4. **מזהים:** Element ID דטרמיניסטי מתפקיד: `F3.COL.L`, `F3.RAF.R`. מזהה מסגרת יציב (`F3`) אינו תלוי במיקום ואינו ממוחזר. Part Mark / Assembly Mark / Drawing Number — מזהים נפרדים (M5).
5. **מקור אמת:** נשמרים רק `building` (פרמטרים), `memberOverrides`, `manualMembers`, `deleted`. הגיאומטריה נגזרת בכל פעם ואינה נשמרת.
6. **התאמה ידנית:** הזזה/סיבוב/שיקוף של אלמנט פרמטרי שומרים מיקום ידני + חתימת המיקום הפרמטרי באותו רגע. אם שינוי פרמטרי משנה את החתימה — `STALE_OVERRIDE` מדווח, והמשתמש מחליט (איפוס או השארה).
7. **פקודות:** כל שינוי = פונקציה טהורה `Project → Project`. פקודה לא חוקית זורקת `CommandError` והמודל לא משתנה. פקודה שאינה משנה דבר אינה נכנסת להיסטוריה. Undo/Redo = מחסנית מצבים.
8. **שמירה:** IndexedDB, טרנזקציה אחת לפרויקט + גרסה; 30 גרסאות אחרונות לשחזור; בדיקת מבנה בטעינה נגד קבצים פגומים; מיגרציות לפי `schemaVersion`.
