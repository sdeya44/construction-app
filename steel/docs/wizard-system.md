| אלכסונים / מכפל |- **WizardDef (רישום משפחה):** `{ id, title, icon, tint, match(id), types?, scopes(ctx), location, geometry: { preview(ctx): RealSet, dims?: DimSystem, fields }, profiles, connectors(ctx), counts(ctx) }`. כל אשף = הגדרה, לא קוד UI חדש.
| אלכסונים / מכפל |- **טרנזקציה (`store.tx`):** פתיחת אשף רושמת נקודת מצב; כל `exec` בתוך האשף נכנס להיסטוריה כרגיל (תצוגה חיה); **אישור** מאחד את כל הצעדים לפעולת Undo אחת; **ביטול** מחזיר לנקודת המצב ומוחק את הצעדים; סגירה בלי הכרעה = אישור (שומר את העבודה). מומש ב-`History` (שינוי קטן, בלי לגעת במנוע).

| אלכסונים / מכפל |- **עיצוב:** טוקנים מרכזיים (`--wz-*`) — צבעים (כחול = בחירה, כתום = שינוי/נעילה, ירוק = תקין, אדום = שגיאה), ריווחים 4/8/12/16, רדיוסים 8/12/16, צל, טיפוגרפיה, מצבי פקד. כל רכיב משתמש רק בהם.

| אלכסונים / מכפל |6. **מהדורה נעולה** — האשף נפתח לקריאה בלבד עם הסבר.
